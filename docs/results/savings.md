## How to read it

- **The baseline** is P4's incremental transcribing in sync mode on the whole sample: $17.85 a video (the P4 report prints the same mean as $17.84 on its all-stages line; the two runs paid $17.77 and $17.92), $0.0808 a frame, $0.263 a question. Of the $17.85, `annotate` is $12.22, `interpret` $4.69, `summarize` $0.94. Questions are priced apart from the video.
- **Per-video figures are linear projections** ($ per frame times 221) wherever the row's span is smoke (11 frames) or span2 (33 frames); only the P4, P4b, P6, P8 and P9 rows are measured on all 221 frames. Projections from span2 land close to the measured whole video (P2b projected $20.22 for the baseline, P4 measured $17.85) because span2's share of target boxes (9.6 %) is near the whole video's (12.1 %); smoke projects high because 21 % of its boxes are targets. The P3, P5 and P7 per-video figures cover `annotate` only (those phases did not run `interpret` or `summarize`), so they are comparable with each other and with P3 `s100`, not with the $17.85 whole-pipeline figure; on the whole sample `annotate` alone cost $12.22.
- **Batch pays 0.68 of sync, not half.** Batched requests mostly write the prompt cache instead of reading it (about 161 of 221 `annotate` calls and 120 of 220 `interpret` calls were cache writes). $12.11 against $17.85 is the measured price; the 50 % figure in the P1 and P2 reports' "batch $" columns is a projection made before batch had run and is not used here.
- **The whole-video question set is saturated.** Every base on the 221-frame sample with frames available scores 27 of 27 (Opus and Sonnet agents alike, with and without annotation), so on that set the differences between variants are in the labels (P3, P5, P7), in the honest text-change contract (P8, P9) and in cost, not in scores. The only score separations in the session are on the short spans: P2a's two sequence questions about the line edited on frame 155, which only the transcribing bases (the second reading) answered, and P6's one rubric line, which only the per-frame description carried.
- **Noise.** Question and command metrics had repeat noise 0 in every phase that measured it, at the ceiling, so they say nothing about noise below the ceiling; with two or three repeats one `outside` difference is weak evidence. Cost noise per frame is $0.0001 to $0.0118 (P1), $0.0007 (P4), $0.0076 and $0.0004 (P3 at 1.0). Label metrics' repeat gaps are given in the P3, P5 and P7 rows.
- **The verdict column** is the ledger's wording, not a new judgment.

## What could not be filled from existing data

1. **P1's baseline is borrowed from P2b.** P1 ran before incremental annotation existed, so the incremental baseline of that span comes from P2b (same span, same 15 questions, same harness), which ran on prompt version 3 where P1 ran on version 2. The comparison crosses that prompt change.
2. **The $ per question column is empty for P3, P5 and P7**, which ran `annotate` alone with no questions; and for the outline stage. Their per-video figures are `annotate` only (see above).
3. **P4b has one run**, so its own repeat noise is unknown; the P4 sync noise ($0.0007 a frame) is the nearest available.
4. **P6 and P9 have no per-frame or per-video saving** by construction (pipelines copied). For the no-annotation rows of P6 and P9 the saving against the working default mixes two changes (no annotation, plus no frames or a Sonnet agent); the same-index comparison is given beside it in the cell.
5. **The outline stage has no per-frame figure** (one Gemini call per video), no repeat noise beyond two runs that disagree on the chapter count (16 against 10), and **no efficacy against the baseline**: no run has compared `interpret` or `summarize` output with and without an outline. Its cost is the manifest's `cost_usd` at list price; the report roll-up skips it (L58).
6. **Every-frame annotation was never run on the whole sample**, so the incremental-against-every-frame saving is a projection from the 11- and 33-frame spans.
7. **Efficacy for P3, P5 and P7 is on labels only.** No phase asked questions over labels made at a reduced scale, under arm D or by Sonnet, so whether those worse labels would cost an answer is not measured (L59 (4) chose the sweep on label measures for that reason; P8 is the nearest evidence, where Sonnet's worse labels cost no answer).
8. **Haiku 4.5 was not tested** on any stage (it does not take the `effort` parameter the pipeline sends, L64).
9. **Judge dollars are not comparable across phases** (`judge_dollars` reads 0 for cached verdicts in P4's scorecards, L66), so they are left out.
10. **Wall time per frame is confounded** by contention in P3 (span2 from 0.3 down) and P4 (four or five processes), so it is not tabulated.
