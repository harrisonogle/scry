# Re-base step 2: implementation notes

One entry per place where the implementation of `2026-09-21-rebase-boxes-2-annotate.md` (Tasks 1 to 11) had to choose,
because a rule was ambiguous, an interface was incomplete, or an expected value did not follow from the rules. Each
entry: the task, what the plan said, what was done, why. The reading that needs the least machinery was taken every
time. Tasks 12 to 15 and the deferred task are not built.
